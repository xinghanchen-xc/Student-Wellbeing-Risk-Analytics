# 50K CPU reference run

These files were generated by the shared modeling pipeline in this repository from `data/sample_50k.csv` after recomputing all eight features using `src/features.py`.

- Rows: 50,000
- Train/test split: stratified 80/20, random seed 42
- Training: XGBoost, CPU
- Inference: CPU
- Class weighting: balanced sample weights computed from the training split
- Model parameters: recorded in `model_metrics.json`
- SHAP: skipped for this quick reference run (`--shap-sample-size 0`); rerun with a positive value to generate SHAP outputs.

Reference holdout metrics from this run:

- Accuracy: 0.8177
- Macro F1: 0.6613
- Weighted F1: 0.8308
- Balanced accuracy: 0.7476
- High-risk precision: 0.3418
- High-risk recall: 0.6309

These results replace the earlier pre-refactor preview metrics. They are a reference snapshot for this included sample, not results from the full 1M-row GPU run. Re-run the pipeline to regenerate results for your environment.
